Caso de Estudio Destacado

🏆 Alke Wallet - Diseño de Base de Datos Relacional

Descripción de la actividad

Diseño e implementación completa de una base de datos relacional para gestionar una wallet digital, incluyendo modelado ER, creación de tablas, relaciones y consultas SQL para operaciones financieras.

Desafío principal

Garantizar la integridad referencial y la coherencia de los datos financieros mediante un diseño normalizado (3FN), aplicación de principios ACID y manejo adecuado de transacciones con múltiples usuarios.

Solución propuesta

Creé un modelo ER con 3 entidades principales (Usuario, Transacción, Moneda), implementé claves foráneas para mantener la integridad, desarrollé consultas SQL optimizadas con JOINs y subconsultas, y apliqué transacciones con COMMIT/ROLLBACK.

Herramientas técnicas

MySQL 8, SQLTools (VS Code), SQL Online, DDL (CREATE, ALTER), DML (INSERT, UPDATE, DELETE), SELECT con JOINs, modelo entidad-relación, normalización 3FN.

Principales aprendizajes

Comprendí la importancia del diseño de bases de datos para la integridad de los datos, aprendí a modelar relaciones complejas, optimizar consultas y aplicar principios ACID en transacciones financieras críticas.

Métricas de impacto

Base de datos 100% normalizada (3FN), 0 errores de integridad referencial, consultas optimizadas que permiten obtener historiales de transacciones en tiempo real, y transacciones atómicas garantizadas.

Habilidades técnicas aplicadas

Diseño de bases de datos relacionales, modelado ER, SQL (DDL/DML), normalización, integridad referencial, transacciones ACID, consultas complejas con JOINs y subconsultas.

Justificación de la elección

Elegí este proyecto porque representa mi primer acercamiento al diseño de bases de datos profesionales. Resolver un sistema financiero real me permitió demostrar mi capacidad para manejar datos críticos con integridad y eficiencia, habilidades esenciales para un desarrollador Full Stack.
